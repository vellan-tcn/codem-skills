## 跨页通用交互规格

### A. 两套控件风格体系（关键区别）

| 维度 | 主平台区（dashboard/energy/alarms/logs/ahu-overview/realtime） | IOServer 管理区（org-scan/devices/gateways/third-gateways/channels 等） |
|---|---|---|
| 输入框/下拉圆角 | 8px（分页条数下拉除外） | 0px（全直角） |
| 控件高度 | 筛选 36、按钮 32 | 一律 32 |
| 边框 | lab(90.952…) ≈ #E7E7E7 | rgb(231,233,241) |
| 筛选字号 | 14px | 12px |
| 分页条数下拉 | 88×32、直角、12px、rgb(96,98,102)（两区一致） | 同左 |

### B. 下拉面板通用契约（所有实测展开面板一致）

- 面板圆角 **0px**、阴影 **none**、面板底色 `rgba(0,0,0,0)`（依赖宿主背景）
- 选项高：普通筛选 32px（14px 字）；IOServer 状态类 34px（12px 字）；分页条数 28px（14px 字）
- 选中项色值随状态：品牌蓝 `lab(44.0605 29.0279 -86.0352)` 或 `rgb(22,119,255)`，未选中近黑 `lab(7.78201 -0.0000149012 0)` / 灰 `rgb(96,98,102)`
- 面板宽 ≈ 触发器宽 + 14~18px（如触发 112 → 面板 128；触发 144 → 142/146；条数 88 → 144）
- 缺省值规则：主平台区下拉缺省显示默认选项文本（`全部`/`全部楼层`/`全部级别`）；IOServer 区缺省显示 placeholder 式「请选择设备状态/网关状态/组织/标签」（未选时为提示文案而非选项）

### C. 分页通用契约（el-pagination 形态）

- 文案序列固定：`共 N 条 | N 条/页 | 上一页 | [页码…] | 下一页 | 前往 | 页`
- 页码按钮 28×28 直角；当前页 bg `rgb(22,119,255)` + 白字 + 同色边框；非当前页白底、字 `rgb(96,98,102)`、边框 `rgb(231,233,241)`
- 「上一页/下一页」48×28 文字按钮（非箭头符号）；首页时上一页置灰 `rgb(192,196,204)`，末页时下一页置灰
- 页码算法：当前页≤4 时显示 `1 2 3 4 5 6 … 末页`（页数多时带 `…`）
- 条数选项各页不同：8/12/16/24（ahu-overview）、10/20/50（logs/device-points/channels）、5/10/15/20（org-scan）
- 「前往 N 页」跳转输入框：56×28、圆角 10px、边框 lab(90.952…)、字 14px、文字色 lab(48.496 0 0)
- 单页数据（共 0/1 条）时仍渲染完整分页，next 为 disabled

### D. 表格通用契约

- 行 hover：主平台区与多数 IOServer 页为 `oklab(0.969998 -0.00000959635 0.0000227094 / 0.5)`（浅灰半透明）；org-scan 页为 el 标准 `rgb(245,247,250)`——同站存在两种 hover，复刻时需按页核对
- 行高：信息密集表 37px（realtime/device-points）、数据表 46~49px（logs 46 / org-scan·devices·gateways·third-gateways 47 / channels·users·roles 49）
