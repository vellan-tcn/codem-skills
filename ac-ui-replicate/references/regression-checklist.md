# ac-ui 回归防护清单（bug 修复必须登记；UI 变更后必须全量回归）

> 机制：每次 UI bug 修复完成后，在此登记一条「回归项」。之后任何 UI 变更/新 bug 修复完成时，
> **必须逐条核对本清单**（跑对应验证），全部通过才算完成——防止「修新 bug 把旧 bug 改回去」。

## 登记格式
- [编号] 一句话描述 | 修复日期 | 验证方法（命令/检查点） | 来源

## 使用规则
1. 修 bug 前先查本清单是否「旧病复发」（重复出现=回归，优先查上次修复的改动是否被覆盖）
2. 修完 bug → 登记 R1xx/R0xx 新条目
3. 任何 UI 变更交付前 → 逐条跑验证，全绿才允许收尾
