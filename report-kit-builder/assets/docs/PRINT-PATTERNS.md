# 打印页通用模式（确认单 / 结算单 / 报表打印）

> 2026-10-10 由 yixing-app 三个打印页（月度报表 / COP 确认表 / 结算单）实测提炼。
> 通用要素沉淀为本文件；项目专属内容（客户名、金额、口径说明）一律留在项目，不进本文件。

## 一、A4 黑白打印五件套（硬性）

1. **全局 @page**：`client/src/index.css` 的 `@media print` 块内固定 `@page { size: A4 portrait; margin: 0; }`——
   margin 0 使浏览器页眉/页脚、URL 均不打印，页边距由打印页内容自身 padding 提供；
2. **页边距**：打印页根容器用 `print:px-[8mm] print:pt-[7mm] print:pb-[7mm]`（顶部底部留白，适配真实 A4 出纸，
   避免内容贴顶/贴底）；仅屏显容器不加 print padding；
3. **缩放适配**：A4 宽度 210mm，宽内容页用 `print:[zoom:0.78]`（或等价 transform scale）整体收进一页宽；
4. **黑白灰阶**：打印页内一律禁用彩色填充——表头用 `bg-black text-white`、数据行 `border-neutral-300`、
   合计/汇总行 `bg-neutral-800 text-white` 且 `font-bold` + 字号放大一档；曲线/图表打印时走黑白线型或灰阶；
5. **工具条不进 PDF**：屏显操作条（返回/打印按钮）加 `.print-toolbar` class，全局 `@media print { .print-toolbar { display:none !important } }`。

另：全局 `@media print` 内保留 `* { -webkit-print-color-adjust: exact; print-color-adjust: exact }`，
黑白场景同样需要该规则保证黑底白字表头正确输出。

## 二、屏显页与打印页分离

- 打印按钮不直接调 `window.print()`，而是 `navigate('/print-<xxx>')` 到独立打印路由，打印页内再放「打印 / 导出 PDF」按钮调 `window.print()`；
- **打印按钮位置**：页面顶部标题右侧，与顶栏其他按钮水平对齐（移动端 36×36 圆形图标钮 `hidden min-h-[36px] min-w-[36px] md:flex md:min-h-0 md:min-w-0 md:px-3 md:py-1`，
  桌面端紧凑胶囊钮 `rounded-full border border-white/20 px-2 text-xs text-white`）——**全应用打印按钮尺寸必须统一**；
- 打印按钮文案保留在按钮上（`打印本页` / `打印`），不要用图标代替。

## 三、整页汇报打印的结构要素（确认单 / 结算单场景）

1. **标题带年份**：`<项目名> · <年份> <单据名>`（如「XX · 2026 年结算单」），单据名与屏显页标题一致或更正式；
2. **区块编号**：`一、二、三、四…` 编号小节；区块内条目用简洁数字序号 `1. 2. 3.`（**禁止 ①② 圆圈字符或圆形 badge 序号**，黑白打印下丑且不居中）；
3. **指标卡**：2~5 个关键指标（全年冷量/电量/COP 等），卡片式 `border rounded` + 居中对齐，线框深度一致；
4. **运营/诉求类长文本**：每项独占一行（`flex flex-col`），标题行加粗 + 描述行小字，**不要分两列**（A4 下两列挤压难读）；
5. **金额类数据**：一律表格化（`<table>` 两列「项目 | 金额」），黑底白字表头，合计行加粗放大并高亮底——**不用四格卡片**；
6. **签字区**：按场景只放需要的确认方（如甲方「确认人签字（盖章）」+ 日期），`mt-12 grid grid-cols-2` 两栏（签字栏 + 日期栏），签字线用 `border-b`；
7. **口径/来源小字**：打印页不放口径说明小字（口径对客户=结算表，说明属内部，放屏显页 ⓘ 悬浮提示即可）；URL/地址一律不打印（@page margin 0 已保证）。

## 四、验证清单

- `?v=N` 破 CDN 缓存后打开打印路由，工具条可见；浏览器打印预览中工具条消失、内容贴 A4 边距正确（顶部底部留白、不贴顶）；
- 黑白核对：表头/合计黑底白字、无彩色残留；URL 不打印；
- 打印页每页不重复显示汇总值（汇总行只在最后一页）；合计行加粗放大；
- 移动端不显示打印按钮的场景（如 COP 对比页），桌面端必须保留。
